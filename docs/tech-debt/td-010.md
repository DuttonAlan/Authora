# TD-010 – The health endpoint reveals the schema version

- **Status:** Open
- **Added:** 2026-10-11
- **Area:** API (`/health`)

## Current state

`GET /health` returns the names of the applied, pending and unknown migrations to anyone, which reveals the exact schema version. It was split off from [TD-003](td-003.md) when the admin API was protected.

## Why

Health checks are called by orchestrators and load balancers, which usually cannot send an Access Token.

## Impact

An attacker learns which version of Authora is running and can pick known weaknesses of it.

## How to resolve

Return only the overall status to anonymous callers, and the details of each check only to authorized callers or internal networks. `/health/live` can stay public.
