# Authora

### Identity. Access. Control.

Authora is a lightweight, self-hosted **Identity and Access Management (IAM) platform** for small projects and applications.

It centralizes authentication and access management in one place, allowing applications to rely on a single identity provider instead of implementing their own authentication systems.

Built around **OAuth 2.0 and OpenID Connect (OIDC)**, Authora provides standardized authentication and authorization flows while keeping deployment, configuration, and maintenance simple.

### Features

- 🔐 **OAuth 2.0 & OpenID Connect** — Standard-based authorization and authentication
- 👤 **Identity Management** — Centralized user and account management
- 🛡️ **Access Management** — Manage roles, permissions, and access policies
- 🔑 **Application Management** — Register and manage applications and OAuth clients
- 🏠 **Self-Hosted** — Keep control over your infrastructure and identity data
- 🪶 **Lightweight by Design** — Essential identity features without unnecessary complexity

### Philosophy

Authora aims to make centralized identity and access management accessible to small projects without the operational overhead of larger identity platforms.

It combines established identity standards with a simple, self-hosted approach.

**Authora — authentication without the overhead.**
