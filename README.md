# Authora

### Simple authentication. Full control.

Authora is a lightweight, self-hosted authentication solution designed for small projects. It provides a simple way to add authentication to your applications without the complexity of larger identity platforms.

Supporting **OAuth 2.0** and **OpenID Connect (OIDC)**, Authora offers standard-based authentication while keeping setup, deployment, and maintenance straightforward.

Built for self-hosting, Authora lets you keep control of your authentication infrastructure and your data.

### Features
- 🔐 Support for OAuth 2.0 and OpenID Connect (OIDC)
- 🪶 Lightweight and simple by design
- 🏠 Self-hosted, with control over your own infrastructure
- 🛠️ Designed for small projects and personal applications
- 🚀 Straightforward setup without unnecessary complexity

Authora — authentication without the overhead.
